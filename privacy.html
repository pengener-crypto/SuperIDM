1. Overview and Core Philosophy

This Privacy Policy and Legal Agreement governs your use of SuperIDM (including the native Windows desktop client, installer, and companion browser extension), developed and published by Kutha SoftWorks ("we", "us", or "our").

SuperIDM is a high-speed, client-side download manager and acceleration utility designed to manage, schedule, and optimize file transfers. We believe in absolute user privacy and data sovereignty: your data belongs to you, and remains strictly on your device.

🔒 Strict Zero-Data Collection Principle

SuperIDM does not collect, record, transmit, sell, or monetize any user personal data, browsing records, IP addresses, or file download contents. There are no tracking scripts, advertisements, or cloud telemetry hooks embedded in any part of this software.

2. Data Handling and Architecture

2.1 Complete Absence of Telemetry

Neither the SuperIDM desktop engine nor the browser extension integrates any third-party tracking services (such as Google Analytics, Firebase, Sentry, or advertising SDKs). The application requires no user accounts, registration, or passwords.

2.2 Local-Only Storage

  • Settings & Preferences: Configuration values (such as concurrent thread counts, speed caps, and download directory paths) are saved strictly inside your local operating system storage directory.
  • Download Records: Task logs and file histories reside exclusively in a local database on your hard drive and are never synchronized to any remote cloud.

2.3 Local Loopback IPC (127.0.0.1)

The browser extension communicates with the SuperIDM desktop engine exclusively via the local loopback address (127.0.0.1) using a locally authenticated session handshake. No network traffic generated between the browser and desktop app ever routes over the public internet.

3. Permissions and Technical Justification

SuperIDM only requests operating system and browser permissions strictly required to execute user-commanded downloads:

  • Network Socket Access (Desktop Client): Required to initiate HTTP/HTTPS requests to download files and media chunks explicitly requested by the user.
  • File System Writing (Desktop Client): Required to assemble downloaded file segments and write the finalized file into the folder selected by the user.
  • Web Request Detection (Browser Extension): Used in memory to sniff direct media stream links (such as MP4 or M3U8 URLs) on pages visited by the user to present a 1-click download button. No URL lists or request payloads are ever transmitted outside your browser.
